Personal-use backup integration

Encrypted recovery copies, stored in the owner's Google Drive.

AIM VPS Backup is a privately operated OAuth integration for transferring encrypted recovery snapshots of AI Investment Manager infrastructure to a Google Drive account controlled by the operator.

Read the privacy policy View public information

Encrypt first

Backup contents are encrypted before cloud upload. Google Drive receives the encrypted archive, not readable database records or recovery keys.

Limited Drive access

The integration requests drive.file permission for files and folders that it creates. It does not ask for unrestricted access to the owner's Drive.

Owner controlled

Backup creation, upload, recovery, retention, authorization and access revocation remain under the operator's control.

Purpose and availability

This application is used for personal infrastructure recovery. It is not a publicly offered storage service, portfolio manager, brokerage connector, trading service or financial advice product. The public website explains the OAuth application; it does not host or display backup files.

Only encrypted backup archives are intended for transfer through this integration. Filenames and ordinary Drive file metadata can still be visible to Google as the storage provider.

Google Drive authorization is optional and can be revoked through the Google Account security settings. See the privacy policy for access, storage and deletion details.

Contact

For general questions about this private-use integration, open an issue in the public information repository. Do not post passwords, OAuth tokens, recovery keys, financial details or other sensitive information in public issues.
